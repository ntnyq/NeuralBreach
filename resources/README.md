# Runtime assets

- `fonts/Rajdhani-Medium.ttf` and `fonts/Rajdhani-SemiBold.ttf`: Rajdhani, distributed under `fonts/OFL.txt`. Embedded for English UI and code cells. CJK text uses installed system fonts.
- `icon-macos.svg`: canonical editable icon with a solid graphite base and five precisely aligned matrix recesses. Geometry and generation are documented in `docs/design/neural-breach/icon-vector.md`.
- `icon.png`: 1024px app icon rendered from the SVG by `make icon`, explicitly selected in `mygo.json`. MyGo derives platform icons from this PNG when packaging.
- `docs/public/icon.svg`, `docs/public/icon.png`, and `docs/public/favicon.ico`: synchronized website assets generated by the same command. The ICO includes 16, 32, 48, and 64px PNG frames.
- `icon-macos-preview.png`: earlier design preview on white; production assets preserve transparency outside the base.
- `menu-background.png`: generated with the built-in imagegen tool from the approved main-menu concept in `docs/public/neural-breach/01-main-menu-v2.png`. The clean environment is embedded; all interactive text and controls are native MyGo elements.
- Music and effects are synthesized by `internal/sound`, with no third-party recordings or runtime downloads.

Remove ALL overlaid UI: remove every logo, Chinese/English text, buttons, menu, borders, HUD lines, corner ticks, footer and numbers. Reconstruct only the underlying cinematic cyberpunk server-room environment. Preserve the original dark burgundy and black industrial setting, cables, luminous red control consoles on the right, distant red towers and restrained cyan accent lights. Composition: 16:9 landscape, right 55% detailed machinery and terminal screens with abstract nonverbal graphics, left 45% very dark low-detail atmospheric negative space where real native menu controls will be rendered later. No readable letters, no logos, no UI frames, no menu, no watermark, no people. Premium photorealistic videogame environment render, dim and legible as a backdrop.
