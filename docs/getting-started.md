# 开始入侵

## 启动

```sh
go mod download
make run
```

应用使用 Go 1.27.3 / MyGo v0.7.1。Linux 桌面需要 GTK 3。Node.js 和 pnpm 只用于文档站。

主菜单提供开始游戏、继续游戏、查看记录、设置、退出游戏。无存档时继续入口禁用；存档损坏时显示恢复入口。首次建议打开「开始游戏 → 新手教程」。

## 怎么玩

1. 观察矩阵和右侧魔偶序列；观察阶段不限时。
2. 从第一行选择一个代码。首次合法输入启动倒计时。
3. 沿所选格子的列选下一个代码，然后沿新格子的行选择，如此交替。
4. 不能重复使用同一个格子。缓冲中的连续代码匹配序列即完成上传，多个目标可以共享重叠部分。
5. 全部上传、缓冲用尽、无路可走或超时会自动结算，也可主动结束。

标准挑战使用新随机种子，参与个人最佳。自由练习可指定十进制种子、选择不限时、请求提示或撤销；同种子重试始终是练习。提示在搜索预算内未找到结果时会说明原因，不会把预算耗尽伪装成无解。

标准挑战和未填写种子的练习按关卡内容在本地去重，重启后仍有效；已有历史、练习及放弃的关卡也会纳入。指定种子或从历史进入练习仍可重复游玩。随机新局必须先保存指纹才能进入，写入失败时会停留在开始页并显示错误。删除或重建本地数据会重置去重记录。

| 难度 | 矩阵 | 缓冲 | 目标 | 限时  |
| ---- | ---- | ---- | ---- | ----- |
| 入门 | 5×5  | 7    | 2    | 90 秒 |
| 标准 | 6×6  | 8    | 3    | 60 秒 |
| 困难 | 7×7  | 9    | 3    | 45 秒 |
| 极限 | 8×8  | 10   | 4    | 35 秒 |

方向键移动焦点，Enter / 空格选码，Tab 切换控件，Esc 暂停或返回，M 静音。失焦和最小化自动暂停，重新聚焦后需主动继续。暂停完全隐藏矩阵和目标，离线时间不扣时。

## 存档与记录

设置、单槽进度和历史位于 `os.UserConfigDir()/neural-breach/data.json`。每次有效选码、暂停和结算都会保存。只有写入成功才显示「已保存」；写入失败仍保留内存进度，可以重试。退出失败时可返回游戏，或明确确认不保存退出。

教程也使用同一个存档槽：进入教程就保存，退出后可从「继续游戏」恢复教学步骤。恢复先进入暂停页，主动继续后才能选码；教程始终不限时，完成或放弃都会清空活动槽，不写入历史或个人最佳。

文件损坏、缺少版本或版本未知时停止写入。「备份并重建数据」会先保存原始字节到同目录的 `.backup-时间戳` 文件，再建立空数据。备份不会自动删除。如果此时修改设置导致保存失败，仍可选择「不保存退出」并再次确认，原文件保持不变，无需先重建数据。

记录页的三个筛选按钮依次循环切换模式、难度、结果。个人最佳只统计当前规则版本的标准挑战。选择记录后可查看复盘、切换到已验证解法、播放步骤或进入练习。JSON 导出全部历史及棋盘快照，CSV 导出成绩摘要；两者均不含活动局和设置。

## 视听与辅助

设置提供三个音量、静音、动态音乐、后台静音和试听。音乐与音效由本地合成器生成，不需要下载音频。暂停使用平滑淡出；无音频设备仍可游玩。

故障效果仅在事件发生时短暂显示在界面边缘。减少动态效果会关闭故障碎片和低时间边缘脉冲。文字缩放支持 100% / 125% / 150%，应用后相应提高最小窗口尺寸。语言支持简体、繁体、英、日、韩，应用设置后生效；取消返回会撤销未应用的音频调整。

## 开发与截图

```sh
make check
make race
go tool mygo vet
make snapshots
pnpm install
pnpm docs:build
```

`make snapshots` 验证五种语言、两种常规尺寸和 150% 文字，并把中文/英文 PNG 放入忽略提交的 `snapshots/`。原生冒烟截图可用 `NEURAL_BREACH_CAPTURE=截图路径 go run . --data 测试数据路径`；应用会在截图后退出。使用独立数据路径，避免影响自己的成绩。
