# 神经裂隙 · 界面设计稿

配套：[完整游戏设计](../../game-design.md) · [界面画廊与视听预览](/neural-breach/index.html) · [图片提示词](./prompts.md)

打开 `docs/public/neural-breach/index.html` 可切换界面，并手动触发短促 Glitch、试听原创合成器氛围。音乐默认关闭，点击「试听音乐」后播放；这是设计预览，不是 MyGo 游戏实现或最终音乐成品。预览支持键盘操作、音量和减少动态效果，不访问外部网络。

图片由内置 imagegen 生成，作为视觉概念稿。规则、分数、缓冲格数、有效选码区域和状态逻辑以游戏设计文档为准；装饰性微小文字与版本号不作为产品规格。第 6 张为了评审同时展示音频与故障效果，实际设置按音频/画面分类。

字体调整见[字体核查](./typography.md)和[真实字体排版预览](/neural-breach/typography.html)。主菜单与入侵界面默认展示字体修订版，第一版保留供对照。
