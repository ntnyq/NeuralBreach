# Logo concept: matrix path

Generated with the built-in imagegen tool. Asset: `../../../resources/logo-matrix-path-concept.png`.

The compact matrix represents the code board. A connected yellow path abstracts first-row entry and alternating column/row traversal. This is a brand concept, not a literal playable board or move-by-move rules diagram. The packaged application icon has not been replaced.

## Prompt

Use case: logo-brand. Create a SINGLE finished professional app icon for NEURAL BREACH, a code-matrix puzzle game. The design must communicate its actual gameplay: start in the first row of a matrix, select codes by alternating vertical and horizontal moves, connect the selected sequence. The user rejected fragmented letter marks and generic square labyrinths. Make this new design visually unified, compact, and unmistakably a matrix-path puzzle.

Design: one square 3-by-3 code matrix, nine substantial square modules tightly fitted with narrow equal gutters. All nine squares form ONE compact square silhouette, not floating scattered elements. On this matrix, a bold, continuous acid-yellow path fuses the selected square cells into a single confident geometric glyph: begin at the TOP LEFT cell, descend to the MIDDLE LEFT cell, move horizontally to the MIDDLE RIGHT cell, descend to the BOTTOM RIGHT cell. This forms one thick connected stepped diagonal, made ONLY of vertical and horizontal segments. The selected cell modules and connectors have the same solid acid-yellow fill, no gaps at joins. The remaining cells are subdued deep desaturated teal, clearly subordinate to the luminous connected yellow glyph. Uniform square terminals, disciplined 90-degree turns, generous line weight. No detached highlights or decorations. The eye should see a single powerful connected stepped symbol first, a compact code matrix second.

Square canvas, uniform very dark plum #100C10 background. Center the matrix at about 64% of canvas width, ample equal margins. Yellow #FCEE09 active path, muted dark teal #234744 inactive cells, no other colors. Clean flat geometric vector-like artwork with perfectly smooth edges and solid fills. Tasteful minimal corner softening, no outlines. Focus on unified silhouette and readability at small size. No letters, no numbers, no text, no maze walls, no circuit traces, no frame, no separate nodes, no dots, no glitch fragments, no gradient, no grain, no glow, no shadows, no 3D, no mockup, no presentation sheet. ONE logo only.
