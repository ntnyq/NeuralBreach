## Prompt

Use case: logo-brand / app icon adaptation. Transform the supplied Neural Breach symbol into a polished solid macOS desktop application icon.

Retain the recognizable acid-yellow connected orthogonal path emblem: broad vertical at upper left, broad horizontal across center, broad vertical at lower right, with a clipped upper-left terminal and clipped lower-right terminal. Retain FIVE small square recesses suggesting code-matrix cells. Improve the recess alignment: all five identical, top and middle-left aligned on the same vertical axis, middle-right and bottom aligned on the same vertical axis, middle three evenly spaced, vertical center spacing matching horizontal center spacing. Do not break the connected emblem into tiles.

The icon MUST have a substantial filled rounded-square base, with smooth continuous macOS-style corners. Base is opaque deep graphite with a subtle plum undertone, softly lit upper-left edge and a very restrained bevel giving it a solid crafted object feel. Acid-yellow emblem appears as one slightly raised solid enamel inlay integrated into the base, broad and clean, occupying about 65% of the base width. Five dark code-cell recesses are filled with the same dark base material, shallow inset wells, NOT see-through holes. The entire icon is one opaque solid object. Sophisticated subtle depth, not an exaggerated chunky toy or floating components. Crisp small-size legibility, quiet material rendering, no neon glow, no decorative circuitry.

Square canvas, straight-on front view without perspective or rotation. Rounded-square base centered, occupies 88% of canvas width and height, equal padding. Outside the rounded-square base only, genuine transparent alpha, with a very soft tight drop shadow. Keep all interior surfaces fully opaque. No text, no numbers, no extra shapes, no background scene, no wallpaper, no Dock mockup, no presentation board, no surrounding frame, no disconnected pieces. Deliver ONE finished app-icon concept.
