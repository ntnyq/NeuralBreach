# 字体核查与修订

核查日期：2026-10-23。

## 游戏界面和官网不是同一套字体

| 场景                         | 字体                                         | 证据与范围                                                                                                                                                   |
| ---------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 游戏内主要英文 UI、菜单、HUD | Rajdhani，Regular / Medium / SemiBold / Bold | [Fonts In Use 的游戏实拍分析](https://fontsinuse.com/uses/60926/cyberpunk-2077-video-game)，结合截图识别，不是 CDPR 官方清单                                 |
| 游戏内小型装饰文字           | Orbitron                                     | 同一实拍分析；本项目首版不引入第三套装饰字体                                                                                                                 |
| 官网标题与长文               | Refinery / Blender                           | 同一分析区分官网与游戏，不能把官网 Blender 当作全部游戏 UI 字体                                                                                              |
| 游戏中文字体                 | 文鼎 UD 晶熙黑体；解包报告名称 G30_D         | [字体替换模组作者的解包报告](https://www.nexusmods.com/cyberpunk2077/mods/26360)。有明确文件名线索，但本轮没有直接核验用户游戏文件，也没有 CDPR 官方字体清单 |
| 中文字体设计特征             | 简洁、笔画切角、可读性及多字重               | [森泽文鼎官方晶熙黑介绍](https://www.morisawa-arphic.com.tw/ar-jing-xi-hei/)支持字形特征；该页面不证明具体游戏采用哪一个版本                                 |

Rajdhani 的设计者是 Indian Type Foundry，字形方正、窄身，支持拉丁字母和天城文；**不含中文**。参见[设计者仓库](https://github.com/itfoundry/rajdhani)。中文不能靠给 font-family 写上 Rajdhani 就“变成原作字体”。

## 本项目修订方案

- 英文菜单和数字使用真实 Rajdhani Medium 500；面板标题和倒计时使用 SemiBold 600；正文 400；只有极少数强调使用 700。
- 代码矩阵也采用 Rajdhani 500，双字符放在固定宽度单元格里对齐。Rajdhani 不是等宽字体，不把它描述为等宽字体。
- 中文以文鼎 UD 晶熙黑体作为还原目标，常规菜单用中等字重，说明文字用常规字重。暂不将商业字体文件加入仓库；进入正式资源阶段需取得适用于应用嵌入和分发的相应字体文件。
- 本次可运行排版预览中的中文使用系统黑体回退，已经明确标注，不能声称是实际晶熙黑。该选择只用于验证字号、字重、间距与中英文层次。
- Logo 仍为单独绘制的品牌字标，不能把 Logo 的破碎斜体扩散到所有菜单、正文和数字。
- 主菜单中文从原稿的粗重展示字减至约 28–30 px 的中等字重；正文 16–18 px；矩阵 28–32 px；倒计时 56–64 px。中文保持正常字宽，不用机械横向压缩冒充窄体。

## 已落地的设计资源

[真实字体排版预览](/neural-breach/typography.html)使用本地 Rajdhani 字体，能对照系统默认字体，并切换 400/500/600/700 字重。其中文标签明确为系统回退。

主菜单与战斗图的 `-v2.png` 是基于上述研究修订的视觉概念图；生成式图片不能保证精确复现某个商业字库，精确拉丁字形以真实字体预览为准。保留第一版 PNG 便于对照，其余页面沿用修订后的排版规范进入实现。

`docs/public/neural-breach/fonts/` 的四个 Rajdhani TTF 直接来自 [Google Fonts 官方仓库](https://github.com/google/fonts/tree/main/ofl/rajdhani)，未修改，附带原始 `OFL.txt`。不包含从游戏中提取的字体，也不包含 Blender、Refinery 或晶熙黑的商业字库。
